# vrProject01 – AR model

Web AR app (AR.js, three.js): a table model shown on a printed marker. Open https://vratislaw.github.io/vrProject01/ on a phone,
tap **Spustit AR**, allow the camera and point it at the printed marker (A4 sheet, black square exactly 120 mm).
Scales 1:200 – 1:5000; north = top edge of the sheet.
