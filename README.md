# vrProject01 – AR model

Web app (model-viewer): a table model in native AR. Open https://vratislaw.github.io/vrProject01/ on a phone, choose the scale
(1:50 – 1:5000) and whole model or structure only, tap **Spustit AR**, point the phone at a table and tap where the model should
stand. It locks there (iPhone: AR Quick Look, Android: WebXR / Scene Viewer); the scale is fixed, rotate it with two fingers.
